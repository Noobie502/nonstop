        About the data

        Routes come from airline-route-data (opens in a new tab), which lists the airlines that operate each route (codeshares are left out).

        Flights, takeoff times and aircraft come from planes tracked by volunteer radio receivers in the last week, via adsb.lol (opens in a new tab) (ODbL). Some regions have few receivers, so a few routes show no flights. Older aircraft records are from OpenFlights (opens in a new tab) (2014).

        We count visits and clicks anonymously with Vercel Web Analytics (no cookies, nothing that identifies you).

        Always check the airline or a booking site before you travel. Map: Natural Earth (opens in a new tab).
